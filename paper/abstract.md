# Abstract

Medical advice in AI-mediated health communication may appear fluent and professional but remain difficult for non-expert users to understand. Dense terminology, compressed reasoning, and numerical findings can increase cognitive burden and make risks or follow-up actions harder to identify. This project proposes MedEase, a cognitive-load-aware explanation system that links semantic-complexity-informed text analysis, cognitive-load classification, and adaptive interface presentation. A TF-IDF and Logistic Regression classifier categorizes medical advice into low, medium, or high cognitive load, and the predicted load drives interface actions such as plain-language summaries, terminology cues, risk highlighting, and collapsible technical details. Evaluation on a manually labeled set achieved 0.828 accuracy and 0.800 macro-F1. A within-subject A/B study with 30 participants showed improved comprehension accuracy, reduced NASA-TLX workload, and shorter task completion time when using the adaptive interface. The project demonstrates how AI systems can move from generating medical advice to presenting it in a cognitively accessible form.
