# A/B Study Design

The project evaluated the adaptive explanation interface through a within-subject A/B study.

## Conditions

Condition A:

```text
Conventional medical-advice display
```

Condition B:

```text
Adaptive explanation interface
```

## Measures

- Comprehension accuracy
- NASA-TLX workload
- Task completion time

## Results Summary

| Measure | Condition A | Condition B |
|---|---:|---:|
| Comprehension accuracy | 0.7600 | 0.8845 |
| NASA-TLX workload | 70.306 | 48.945 |
| Task completion time | 293.967 s | 257.233 s |

The paired study included 30 participants with complete A/B observations.
