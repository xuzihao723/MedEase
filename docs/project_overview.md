# Project Overview

MedEase is a research prototype for improving how non-expert users understand medical advice produced or mediated by AI systems.

The project is built around one research idea:

```text
semantic complexity -> cognitive load -> adaptive explanation interface
```

The system does not attempt to diagnose disease. Instead, it helps users interpret medical text by presenting explanations in a form that is easier to read, scan, and act on.

## Research Questions

1. Can medical advice text be categorized by cognitive-load level?
2. Can semantic complexity indicators support this classification?
3. Can an adaptive explanation interface improve comprehension and reduce workload?

## System Components

- LLM explanation generation
- Cognitive-load estimation
- Semantic complexity feature extraction
- Adaptive UI policy mapping
- Frontend explanation interface
- User study and system trace analysis

## Audience

This project is intended for AI, HCI, data science, and responsible-AI reviewers who want to see a complete research-to-system pipeline.
